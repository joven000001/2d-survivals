# Google AI Studio Import

This folder contains the current Pixel Frontier project, with its source and build configuration in the original directory structure. The next planned feature is **ANIMAL HUNTING AND MEAT DROPS**.

Google AI Studio's file upload support depends on the specific workflow. Its documented Gemini file inputs include formats such as HTML, CSS, plain text, JavaScript, and JSON; TypeScript and TSX files are not listed as supported file input types. AI Studio may therefore not accept `.ts` and `.tsx` files as direct prompt uploads. This does not change the project files; use a project/code editing workflow that supports the full folder when continuing development.
